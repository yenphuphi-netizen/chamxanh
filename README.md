# Chạm Xanh - Mini Shop Next.js

Dự án website thương mại điện tử mỹ phẩm & chăm sóc thiên nhiên "Chạm Xanh", được xây dựng với Next.js và React.

## 🚀 Tính năng chính
- Danh mục sản phẩm thiên nhiên (dầu gội bưởi, toner trà xanh, tẩy tế bào chết cafe,...)
- Giỏ hàng & thanh toán trực tuyến
- Quản lý tài khoản khách hàng, danh sách yêu thích
- Trang liên hệ và giới thiệu thương hiệu

## 🛠️ Cài đặt & Chạy cục bộ
```bash
# Cài đặt thư viện
npm install

# Khởi chạy máy chủ phát triển
npm run dev
```

Mở [http://localhost:3000](http://localhost:3000) trên trình duyệt để trải nghiệm.
